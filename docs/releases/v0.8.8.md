# ScriptCraft v0.8.8

Released: 2026-11-18

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. The in-app installer verifies the
> download and replaces the app, but it cannot bypass Gatekeeper/SmartScreen
> until those builds are signed. This is not a silent updater and not a
> notarised distribution.

## Highlights

v0.8.8 closes the four items reported after v0.8.7: updates can be installed
from inside the app, the page grid is the standard 1/6-inch screenplay leading,
KIT Scenarist's own light and dark colours replace the earlier imitation, and a
Linux crash now leaves a log to diagnose.

### Install updates from the app

The update prompt now installs instead of sending the writer to a web page:

- **Download and verify.** **Install update** fetches the archive for this
  platform and its published `.sha256` with `curl`, then checks the digest with
  `sha2`. A mismatch, a missing asset, a timeout or a cancelled download leaves
  the installed copy untouched and shows the reason in the prompt.
- **Replace and relaunch.** A small helper script (PowerShell on Windows,
  `sh` on macOS/Linux) waits for ScriptCraft to exit, unpacks the archive,
  replaces the app in place and relaunches it. On macOS the DMG is mounted with
  `hdiutil`, the `.app` is copied with `ditto` and the old copy is restored if
  the copy fails. Unsaved script and title-page edits are saved before the
  install starts.
- **No silent updates.** The prompt always asks first. **Later** dismisses it
  for this launch, **Release notes** still opens the GitHub release, and a
  running download can be cancelled. Files are staged in
  `updates/<version>/` under the per-user config folder.
- **Honest limits.** The checksum proves the transfer, not the publisher.
  macOS builds are ad-hoc signed and Windows/Linux builds are unsigned, so the
  operating system may still warn about the downloaded app. An install started
  from a read-only location (for example a mounted DMG) fails with a message
  asking the writer to move the app to Applications.

### Page grid matches KIT Scenarist

- **1/6-inch leading.** The editor and PDF now use the standard 12 pt screenplay
  pitch, 25.4 / 6 = 4.233 mm per row, instead of Courier Prime's font-defined
  hhea height (4.754 mm). Both share `ROW_MM`; the build script that derived the
  pitch from the bundled font is gone, so swapping a font can no longer change
  pagination.
- **58 lines on A4.** The Russian template's page holds 58 lines, which is what
  A4 minus KIT's 25 mm top and bottom margins leaves at the standard pitch. The
  same script now lands on the same KIT page count instead of running roughly 7%
  long.
- **Regenerated goldens.** The parity fixtures and page-scale smoke test were
  rebaselined deliberately; `FINAL_DRAFT_A4` pagination and wrap hashes did not
  change.

### KIT Scenarist's published colours

- **Light and dark.** **KIT Scenarist** uses the published light set
  (`#fefefe` background, `#000000` text) and a new **KIT Scenarist Dark** uses
  the dark set (`#3d3d3d` background, `#ebebeb` text). The purple folder colour
  (`#9922cb`) is lifted to `#c77cf0` for the UI accent so it stays legible on
  the dark page; the light folder grey (`#cbc6c3`) is deepened to `#6f6a66` for
  the same reason.
- **29 palettes.** The grouped theme dropdown now lists KIT Scenarist and KIT
  Scenarist Dark under ScriptCraft, then every base Omarchy palette.

### Linux crash reporting

The Linux typing crash could not be root-caused without a reproduction,
distribution or session type. As a mitigation, an escaping panic now appends
the payload, source location, version, OS/arch and (when `RUST_BACKTRACE=1` is
set) a backtrace to `panic.log` in the per-user config folder. The file is
capped at 64 KiB and rotated, so a panic loop cannot fill the disk. Attach that
file to a bug report. The crash itself is **not** claimed fixed.

## Verification

- **Installer:** `asset_selection_matches_os_and_architecture`,
  `checksum_parser_reads_the_published_format`,
  `sha256_verification_accepts_the_matching_file_only`,
  `helper_script_waits_for_the_app_and_takes_paths_as_arguments`,
  `helper_script_is_valid_shell_syntax` (runs `sh -n` on the generated helper),
  and the interaction tests `update_prompt_offers_install_and_later`,
  `update_prompt_starts_and_cancels_an_install_offline` and
  `update_prompt_reports_a_failed_install_and_retries`. The Windows helper is
  PowerShell and cannot be parsed on this host; its paths are arguments, not
  interpolated text.
- **Page grid:** `row_pitch_is_the_standard_one_sixth_inch`,
  `the_grid_holds_the_kit_line_count`, the layout placement/PDF tests and the
  rebaselined parity goldens.
- **Palettes:** `kit_scenarist_uses_the_published_colours`,
  `theme_keys_and_labels_are_unique`, `every_theme_paints_from_its_own_palette`;
  snapshot `36_script_kit_scenarist_dark` samples `#3d3d3d` paper.
- **Crash log:** `entry_names_the_version_platform_and_location`,
  `backtrace_is_optional_and_appended_verbatim`,
  `append_keeps_earlier_entries_and_creates_the_folder`.
- Full workspace tests, clippy `-D warnings`, `cargo fmt --check`,
  `cargo deny check` and `git diff --check` pass before the release commit.

## Deferred

Developer ID signing and notarisation, Windows code signing, and root-causing
the Linux typing crash remain deferred. The installer needs signed builds to
avoid Gatekeeper/SmartScreen warnings.
