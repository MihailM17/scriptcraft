# Kino Scenarist v0.9.2

## Highlights

- **Fixed Windows Caption Buttons:** Fixed Minimize, Maximize/Restore, and Close controls in the Windows frameless toolbar so they always receive clicks cleanly without being intercepted by the toolbar drag strip or top-right edge resize zone, and stay accessible in fullscreen.
- **Settings-Driven Automatic `(CONT'D)`:** Removed the `(CONT'D)` buttons from the right-hand Format panel and moved automatic continuation purely into **Settings ▸ Writing ▸ View ▸ Automatic `(CONT'D)` for continued dialogue**, displaying `(CONT'D)` live across the Script editor, Shots view, and PDF exports (regular script, colored script, and Director's Breakdown) without mutating script text.
