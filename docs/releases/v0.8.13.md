# ScriptCraft v0.8.13

Released: 2026-11-19

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. The in-app installer verifies the
> download and replaces the app, but it cannot bypass Gatekeeper/SmartScreen
> until those builds are signed. This is not a silent updater and not a
> notarised distribution.

## Highlights

v0.8.13 tunes the contrast, surface depth and legibility across the six writer palettes, fixes the macOS dock icon enlargement on startup, and updates project documentation.

### 1. Writer Palettes Legibility & Surface Depth

All six writer themes added in v0.8.12 (*Midnight Ink*, *Amber Projector*, *Noir Emerald*, *Velvet Curtain*, *Red Light*, and *Paper and Rust*) have been re-calibrated:

- **Page-on-Desk Separation:** Recessed the desk well backgrounds so the script page floats with clean elevation and distinct border geometry rather than melting into the workspace.
- **Control & Button Visibility:** Increased contrast between button surfaces, input fields and the surrounding window chrome.
- **Secondary Text Readability:** Boosted contrast of `disabled_text` (scene numbers, folder counts, non-printable notes, status bar indicators) to 5.3:1 – 6.4:1 across all six themes.
- **Paper and Rust (Light Theme):** Deepened secondary label contrast on warm parchment from 3.5:1 to 6.4:1.

### 2. macOS Dock Icon Sizing

- Fixed an issue where opening the app caused the Dock icon to visibly expand / enlarge on macOS.
- Bundled `.app` instances now preserve macOS's native multi-resolution `ScriptCraft.icns` without overriding `NSApp.applicationIconImage`.
- Unbundled development runs (`cargo run`) use `ScriptCraft-1024.png` with standard Apple HIG 100px margins (824px squircle) to ensure uniform sizing with native system apps.

### 3. Documentation & Showcase

- Refreshed GitHub repository layout with structured feature showcases, interchange matrices, and Criterion performance budgets.
