# ScriptCraft v0.8.10

Released: 2026-11-19

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. The in-app installer verifies the
> download and replaces the app, but it cannot bypass Gatekeeper/SmartScreen
> until those builds are signed. This is not a silent updater and not a
> notarised distribution.

## Highlights

v0.8.10 fixes the PDF body weight introduced in v0.8.9.

### The PDF body is regular again, like KIT Scenarist

v0.8.9 set every printed body line in bold. That was based on the Courier New
Bold font embedded in KIT's PDF, but the rendered pages do not use it for the
body: KIT prints the script in **regular Courier New**, with bold reserved for
the title-page title and the page numbers.

- **Body text is regular** again: scene headings, action, character cues,
  parentheticals, dialogue, lyrics, transitions, `(MORE)`, `(CONT'D)`, shot
  lines and dual-dialogue cells.
- **Bold stays where KIT has it:** the underlined title-page title and the
  `N.` page numbers in the top-right margin.
- **No layout change.** The editor and PDF still share the same page grid and
  the parity test compares every page line by line.

Markdown export, Fade In import/export, the website and everything else from
v0.8.9 are unchanged.

## Verification

- `a95_pdf_matches_editor_layout` compares the editor and PDF line by line,
  including the bold flag, and `a95_exports_valid_pdf` parses the output.
- The A95 reference export was rendered and compared against KIT's printed
  pages: regular body, bold title, bold page number.
- Full workspace tests, clippy `-D warnings`, `cargo fmt --check`,
  `cargo deny check` and `git diff --check` pass before the release commit.

## Deferred

Markdown import (export is one-way), Fade In revision colours, Developer ID
signing and notarisation, Windows code signing, and root-causing the Linux
typing crash remain deferred.
