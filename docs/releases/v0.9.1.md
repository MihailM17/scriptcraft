# Kino Scenarist v0.9.1

## Highlights

- **Rebranded to Kino Scenarist:** New app name across the UI, macOS/Windows/Linux bundles, website, and documentation (preserving full backward compatibility with existing `.kitsp` projects, settings, and backups).
- **Frameless Integrated Titlebar on Windows:** Removed the oversized OS title bar on Windows so the top toolbar doubles as sleek window chrome with native-style Minimize, Maximize/Restore, and Close controls, drag-to-move, double-click maximize, edge resizing, and Windows 11 rounded corners—matching macOS.
- **Overhauled Director's Breakdown PDF Floor Plans:** Larger side-by-side layout for square/vertical rooms with a dedicated color-coded **Camera Key**, proportional numbered camera badges matching the shot cards below, FOV sightlines tracing cleanly over tables and furniture, exact frame clipping, and collision-free actor name pills.
- **Full `.fdx` Opening Everywhere:** Fixed macOS Finder double-click / *Open With* via native AppKit delegate hooks and UTI declarations, added `.fdx`/`.fadein`/`.fountain` support to `File ▸ Open` and window drag-and-drop, and hardened FDX parsing for UTF-8 BOM, UTF-16, `<HeaderAndFooter>`, `<SceneProperties>`, and nested `<ScriptNote><Paragraph>` nodes.
- **Cut Count & Average Cut Duration (ASL):** Displays editorial cuts and average cut length alongside shot counts across the Shots header, scene list, scene sheets, Shot List PDF, and Director's Breakdown PDF.
- **`(CONT'D)` Dialogue Continuation:** Added a Format panel **`(CONT'D)`** toggle (`Cmd/Ctrl+Shift+C`), one-click **`Auto (CONT'D) All`** script sync, character `(` extension autocomplete (`(CONT'D)`, `(V.O.)`, `(O.S.)`, `(O.C.)`, `(PRE-LAP)`, `(FILTERED)`), an optional **Auto-add `(CONT'D)`** Editor setting, and clean page-break deduplication.
