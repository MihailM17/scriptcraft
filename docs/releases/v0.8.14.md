# ScriptCraft v0.8.14

Released: 2026-11-19

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. The in-app installer verifies the
> download and replaces the app, but it cannot bypass Gatekeeper/SmartScreen
> until those builds are signed. This is not a silent updater and not a
> notarised distribution.

## Highlights

v0.8.14 fixes button highlight and selection contrast on the writer themes, adds dynamic high-contrast ink for solid accent buttons, and fixes the macOS Dock icon fallback when opening bundled application instances.

### 1. Selected Row & Button Highlight Contrast

- **Premultiplied Alpha Correction:** Fixed an issue where active navigation rows (such as Settings page items) and button chips blended into glowing backgrounds on the six writer themes (*Midnight Ink*, *Amber Projector*, *Noir Emerald*, *Velvet Curtain*, *Red Light*, and *Paper and Rust*).
- In `egui`, `Color32::from_rgba_premultiplied` expects channels pre-scaled by alpha ($r, g, b \le a$). Previously, unmultiplied RGB values caused the GPU blend stage to emit a 100% additive neon glow instead of a 20% dark tint.
- Re-calibrated `accent_soft` across all six palettes to true premultiplied values, restoring clean depth and delivering **5.6:1 – 7.4:1 contrast** (exceeding the WCAG AAA 7:1 standard on *Noir Emerald*).
- Added regression tests in `every_theme_is_legible` to enforce valid premultiplied alpha and $\ge 4.5:1$ chip contrast across all 35 palettes.

### 2. Dynamic Accent Ink for Solid Buttons

- Added an `ink_on_accent` contrast helper to ensure solid primary buttons (`Save`, `Update`, `Start` actions) dynamically choose between dark ink (`#0E1217`) and white based on the palette accent's relative luminance.

### 3. macOS Dock Icon Native Rendering

- Fixed an issue where opening the bundled `.app` caused macOS Dock to display the framework's fallback `"e"` logo.
- Bundled `.app` instances now pass `egui::IconData::default()` to eframe, preventing fallback injection and runtime `NSApp.applicationIconImage` overrides so macOS natively renders `ScriptCraft.icns` with exact Apple HIG squircle geometry.
- Development runs (`cargo run`) continue to use the HIG-standard `ScriptCraft-1024.png` (824px squircle).
