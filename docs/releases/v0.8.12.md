# ScriptCraft v0.8.12

Released: 2026-11-19

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. The in-app installer verifies the
> download and replaces the app, but it cannot bypass Gatekeeper/SmartScreen
> until those builds are signed. This is not a silent updater and not a
> notarised distribution.

## Highlights

v0.8.12 adds six writer themes to the palette picker.

### The six writer themes

The Settings ▸ Appearance theme dropdown grows from 29 to 35 palettes: the
ScriptCraft family now carries twelve entries (Midnight, Light, Sepia, High
Contrast, KIT Scenarist in KIT's published light and dark colours, plus the six
writer themes below), and the Omarchy family keeps its 23 imported base themes.

- **Midnight Ink** — cool, calm, closest to the current Midnight look.
- **Amber Projector** — warm, like light through a film gate.
- **Noir Emerald** — moody green, easy on the eyes at night.
- **Velvet Curtain** — theatre plum with a crimson accent.
- **Red Light** — neutral graphite with one REC red accent.
- **Paper and Rust** — light theme, like a printed script.

Each theme maps the editor design brief's colour roles onto the same semantic
fields the original Midnight and Light palettes use (window, panel, page, text,
muted, accent), so every painted widget follows without a per-theme branch and
script page text stays monospace with colour changes only.

- **Dark and light both covered.** Red Light is a dark palette; Paper and Rust
  is a light palette, and both join `Theme::is_light`, so the page keeps its
  paper treatment.
- **Contrast-tested.** `every_theme_is_legible` now walks all thirty-five
  palettes; revision colours stay industry-standard and unthemed on each.

## Verification

- `theme_picker_switches_between_dark_palettes` switches through the real
  Settings UI to the new Midnight Ink palette and checks the repaint.
- `30_settings_theme_menu` snapshot regenerated for the longer list.
- Full workspace tests, clippy `-D warnings`, `cargo fmt --check`,
  `cargo deny check` and `git diff --check` pass before the release commit.
