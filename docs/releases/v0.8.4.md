# ScriptCraft v0.8.4

Released: 2026-11-14

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8.4 is about the writing surface: live spellchecking in the three languages
the app already typesetting supports, and a theme table that no longer stops at
dark and light.

### Spellchecking

- **Live marks while you type** in English (US), Bulgarian and Russian. The
  dictionaries are Hunspell data files loaded at runtime, so they can be added,
  replaced or removed without rebuilding the app.
- **Screenplay-aware by default.** Scene headings, character cues and sound
  effects are ALL CAPS and are skipped, so `INT.`, `MARA` and `BANG` do not
  light up red. Words with digits (`3rd`, `COVID-19`) are skipped too.
- **Right-click a flagged word** for up to six suggestions, **Add to
  dictionary** (written to `custom-dictionary-<lang>.txt` in the config folder
  and kept across launches) or **Ignore** for the session.
- **Off by default.** A Bulgarian or Russian script would light up on first run
  before the writer picked a language, so Settings ▸ Scenario Editor ▸ Spelling
  turns it on. The language chooser and the ALL-CAPS toggle sit next to it.
- **Dictionaries travel as data.** `assets/dictionaries/{en_US,bg_BG,ru_RU}`
  contain the `.aff`/`.dic` pairs and their own licence files; packaging copies
  the folder next to the executable (macOS: `Contents/Resources`). No dictionary
  is compiled into the binary, and removing a folder removes that language.
- The checker keeps a per-paragraph cache keyed by the paragraph's text hash, so
  only visible lines are checked and edits invalidate naturally. A parsed
  dictionary is reused; switching a disabled engine's language frees the old
  one.

### Themes

- **Eight palettes**: Midnight, Tokyo Night, Nord, Gruvbox, Rosé Pine, Light,
  Sepia and High Contrast, chosen in Settings ▸ Theme.
- Every palette is contrast-tested (body text, muted text, accent and accent
  text against the page), and the misspelling underline is part of the palette
  so it clears 3:1 on every page.
- **Revision colours stay industry-standard** — Blue, Pink, Yellow, Buff,
  Goldenrod, Green, etc. do not follow the theme. Pale marks get a 1 px edge so
  they stay locatable on white and cream pages.
- The selection tint and current-line band derive from the theme accent instead
  of a hard-coded blue; Midnight and Light remain pixel-identical to v0.8.3.

## Compatibility and data safety

- No project, save or import/export format changed. Spellcheck settings live in
  `settings.conf`; a missing or unknown value keeps the previous behaviour
  (off / English).
- Custom dictionaries are plain text files outside the project, so they cannot
  corrupt a script.
- Dictionaries are separate data files under their upstream licences (SCOWL /
  Ispell terms for English, BSD-style for Russian, GPL-2.0 for Bulgarian); see
  `NOTICE` and the licence file inside each dictionary folder.

## Known limitations / deferred

- **One dictionary at a time:** a bilingual script flags the other language
  until you switch or add the words. Per-project dictionaries are deferred.
- **No grammar checking**, no style suggestions; this is a speller.
- **macOS distribution:** ad-hoc signed unless built with Developer ID +
  notarisation (ignored while there is no Apple Developer account). Users may
  need to allow the app in system settings.
- **Windows:** unsigned packages; SmartScreen instructions apply (see
  `docs/release-checklist.md`).
- **Auto-update:** deferred — no silent updater.
