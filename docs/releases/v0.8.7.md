# ScriptCraft v0.8.7

Released: 2026-11-17

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8.7 is the Windows desktop experience, reported from the v0.8.6 build: a
light-mode desktop put white menus on top of the app, the File / Edit / Script /
View / Window / Help bar that Windows needs was missing, the title bar showed
as a white strip above the dark toolbar, and Explorer showed no app icon on
`ScriptCraft.exe`.

### Windows desktop

- **Light mode keeps the app dark.** The white menus were an egui preference
  bug, not a palette bug: `apply_theme` styled only the active style slot while
  the theme preference still followed the operating system, so a light-mode
  Windows desktop replaced every menu, popup and window with stock egui light
  visuals. The preference is now pinned to the palette that was just built, and
  a regression test drives the system-theme change in both directions.

- **A real menu bar on Windows and Linux.** The toolbar now carries File, Edit,
  Script, View, Window and Help with the same commands as the macOS native menu
  (imports, revisions, view toggles, zoom, minimise / maximise / close, Settings,
  Help, About). Shortcut hints read `Ctrl+…` on Windows/Linux instead of `⌘…`.

- **The title bar follows the palette.** The Windows native title bar is now
  tinted from the active palette through DWM (immersive-dark plus caption, text
  and border colours) instead of sitting as a white band above the dark toolbar
  on a light desktop.

- **The `.exe` shows the ScriptCraft icon.** The icon is embedded as a Windows
  resource at build time (the runtime window icon now uses the cropped variant of
  the artwork) and Explorer reads it from the executable.

## Verification

Menu-bar behaviour is covered by
`inline_menu_bar_has_every_native_menu_and_opens_help`; the theme fix by
`a_system_theme_change_does_not_replace_the_palette`; the title-bar and icon
changes are Windows-only and cannot be exercised by the offline UI suite. The
Windows code paths type-check for `x86_64-pc-windows-msvc`. Snapshot suite
unchanged (the new menu bar is Windows/Linux-gated).

## Deferred

Developer ID signing and notarisation, Windows code signing and **true
auto-update** remain deferred (external credentials). ScriptCraft can tell you a
release exists and open its page; it cannot install it.
