# ScriptCraft v0.8.3

Released: 2026-11-13

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8.3 makes the Draft Comparison workspace easier to read on a real script.
The engine and every existing behaviour are unchanged: comparison stays
read-only, the diff still comes from the same stable-ID `DraftDiff`, and the
keyboard controls and filter labels are the same.

- **Changes with context, not the whole script.** Compare now opens in
  changes-only mode: every change keeps two unchanged blocks above and below
  it, the first block of each affected scene is always shown, and every other
  unchanged run collapses into one row — “N unchanged blocks · click to
  show”. Clicking the row reveals that run in place.
- **Whole script on demand.** A new `Show unchanged` checkbox in the header
  switches back to the full script and hides the gap rows. Identical drafts
  now show a dedicated **No differences** state with a **Show full script**
  button instead of a wall of unchanged rows.
- **Screenplay indentation.** Diff rows follow the printed template columns:
  character cues, parentheticals and dialogue are indented using the same
  millimetre metrics as editor and PDF (`cue_mm`, `paren_mm`, `dialog_mm` of
  the Russian geometry divided by `TEXT_W_MM`). The same columns apply in
  unified and side-by-side views, and removed blocks take their element type
  from the base revision.
- **Compare is reachable from Research.** `Compare Drafts…` moved from the
  bottom of Research ▸ Versions to the Research module header, so the
  workspace opens from every Research pane. It stays disabled until a
  revision exists.

## Verification

- Full workspace gate green: `cargo fmt --all -- --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`, `cargo deny check`, `git diff --check`.
- App: 34 lib tests, 55 interaction tests, 21 snapshots. Core: 100 lib + 49
  integration. Layout: 26 unit + 25 integration.
- New unit tests cover context/run collapsing, gap expansion, the full-script
  mode, scene anchoring and the template indentation ratios. New interaction
  tests cover the identical-draft empty state and gap expansion.
- Snapshots regenerated for the new default layout (`14_compare_drafts`,
  `15_compare_side_by_side`, `21_compare_light`) plus new
  `22_compare_identical`.
- CI run on the release commit is green.

## Compatibility and data safety

- No data format, save or import/export behaviour changed.
- Compare continues to read only; no project or revision history mutation.
- `DraftDiff` / `CompareState` are unchanged in name and purpose; no new
  dependency was added.

## Known limitations / deferred

- **macOS distribution:** ad-hoc signed unless built with Developer ID +
  notarisation (ignored while there is no Apple Developer account). Users may
  need to allow the app in system settings.
- **Windows:** unsigned packages; SmartScreen instructions apply (see
  `docs/release-checklist.md`).
- **Auto-update:** deferred — no silent updater.
- **Still out of scope for v0.8:** collaboration, plugins, production
  breakdowns, DOCX/RTF, spellcheck, AI.
