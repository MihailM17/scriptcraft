# ScriptCraft v0.8.5

Released: 2026-11-15

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8.5 fixes the writing surface itself: clicks land on the character you
aimed at, double-click selects a word, drag-selecting starts at the press, and
typing a space can no longer move the caret while leaving the page unchanged.

### Editor input

- **Clicks and carets map through collapsed whitespace.** The page renders a
  run of spaces as one cell (screenplay grid), but hit-testing and caret
  geometry used to assume one screen cell per source character. After a double
  space — common after a period — every position was a few characters off, so
  a click on a visible word could land inside the invisible run. Each wrapped
  line now carries a display-column → source-character map used by clicks,
  the caret, selection painting, spelling underlines, Up/Down, Home/End and
  line-boundary motion. `End` lands on the last *visible* character, not in
  the invisible wrap gap; right-aligned lines measure their display width.
- **A click places the caret where the button went down.** egui delivers
  `clicked()` on release, after it has forgotten the press origin, so a few
  pixels of mouse drift could move the caret to the next cell. The editor now
  remembers the press point. Dragging anchors there too, instead of at the
  point reached after egui's drag threshold — selections start exactly where
  you pressed.
- **Double-click selects the word under the pointer; triple-click selects the
  paragraph.** A click on the right half of a word's last letter lands just
  past it, so the word lookup falls back one character.
- **Typing never lies about the caret.** If an edit command is rejected, the
  caret stays put instead of sliding forward with no text behind it. A failed
  command sequence is reported in the status bar rather than silently dropped.

## Verification

- Full workspace gate green: `cargo fmt --all -- --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`, `cargo deny check`, `git diff --check`.
- App: 51 lib tests, 61 interaction tests, 24 snapshots. Core: 100 lib + 50
  integration. Layout: 27 unit + 25 integration.
- New layout test pins the per-line column map across collapsed whitespace and
  strengthens the wrap tiling invariants. New app test clicks through a
  collapsed run. New interaction tests cover double-click word selection,
  triple-click paragraph selection, the drag anchor and a space typed after a
  click on a word that follows a collapsed run.
- No snapshot changed: this release corrects geometry and input, not visuals.

## Compatibility and data safety

- No project, save, import/export or settings format changed. `.kitsp`, FDX,
  Fountain, revisions, page locks and spellcheck dictionaries behave exactly as
  in v0.8.4.
- Undo/redo history is unchanged; the fixes only affect where a caret and
  selection sit.

## Known limitations / deferred

- **One dictionary at a time:** a bilingual script flags the other language
  until you switch or add the words. Per-project dictionaries are deferred.
- **No grammar checking**, no style suggestions; this is a speller.
- **macOS distribution:** ad-hoc signed unless built with Developer ID +
  notarisation (ignored while there is no Apple Developer account). Users may
  need to allow the app in system settings.
- **Windows:** unsigned packages; SmartScreen instructions apply (see
  `docs/release-checklist.md`).
- **Auto-update:** deferred — no silent updater.
