# ScriptCraft v0.8.0

Released: 2026-11-10

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8 makes revisions usable across a production cycle while keeping `.kitsp`
compatibility and local-first, offline editing.

- **Stable identity (M0):** block/scene IDs survive save/reopen and external
  KIT edits via versioned sidecars (`scriptcraft_ids`, `scriptcraft_scene_meta`).
- **Revision diff and compare (M1–M2):** deterministic draft comparison and a
  read-only compare workspace with jump-to-editor.
- **Restore as copy (M3):** restore any baseline into a new `.kitsp` without
  overwriting the current draft.
- **Omitted scenes (M4):** sidecar-only omission keeps heading/number/identity;
  body excluded from pages, stats and PDF; page labels carry across the gap.
- **Dual dialogue (M5):** two-column layout with editor/PDF parity and FDX
  interchange.
- **Title page editor (M6):** form + live A4 preview painted from the exporter’s
  layout; PDF/FDX parity.
- **Revision summary (M7):** scene-grouped added/removed/changed counts, page
  baseline, selectable baseline, deterministic UTF-8 CSV (BOM) and printable A4
  PDF — counts derived from the same diff as compare.
- **Release/tooling progress (M8):** `ROW_MM` generated from bundled font
  metrics, Criterion benches/baselines, unknown `scenario_data` preserved on
  save, release checklist and macOS bundling script, CI interaction smoke and
  binary launch probes on Linux/Windows.
- **Refactor/docs (M9):** extracted view modules (`compare_view`, `title_page`,
  `revision_summary`, `dialogs`) and updated plan/docs; migration guide added.

## Compatibility and data safety

- Reads/writes KIT `.kitsp`; preserves unknown `scenario_data` rows on save.
- Atomic saves, recovery copies and crash restore flow remain in place.
- Fountain and Final Draft `.fdx` import/export supported for mapped features.

## Known limitations / deferred

- **macOS distribution:** ad-hoc signed unless built with Developer ID +
  notarisation (ignored if no Apple Developer account). Users may need to allow
  the app in system settings.
- **Windows:** unsigned packages; SmartScreen instructions apply (see
  `docs/release-checklist.md`).
- **Auto-update:** deferred (v0.8.1) — no silent updater.
- **CI:** macOS runs full tests/snapshots; Linux/Windows run runtime smoke and
  interaction tests but not pixel snapshot baselines.
- **Still out of scope for v0.8:** collaboration, plugins, production
  breakdowns, DOCX/RTF, spellcheck, AI.

- `cargo deny check`
