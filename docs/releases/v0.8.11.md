# ScriptCraft v0.8.11

Released: 2026-11-19

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. The in-app installer verifies the
> download and replaces the app, but it cannot bypass Gatekeeper/SmartScreen
> until those builds are signed. This is not a silent updater and not a
> notarised distribution.

## Highlights

v0.8.11 adds Liberation Mono as a page face.

### Liberation Mono

**Settings ▸ Appearance ▸ Script font** now lists **Liberation Mono
(Latin + Cyrillic)** alongside Courier New, IBM Plex Mono and Courier Prime.

- **Bundled, not system-dependent.** Regular, Bold and Italic ship with the app
  under the SIL Open Font License, so the choice behaves the same on macOS,
  Windows and Linux.
- **One design for both scripts.** Liberation Mono covers Latin, Greek and
  Cyrillic, so mixed English/Bulgarian/Russian pages no longer borrow glyphs
  from a second face.
- **Metric-compatible with Courier New.** It keeps the 0.6 em advance used by
  every other page face, so scene numbers, line breaks and page counts do not
  move. The editor installs it immediately and the PDF exporter embeds the
  same Regular and Bold files.
- **Not the new default.** Courier New stays the default when the system has
  it; Liberation Mono is an explicit choice and survives restart in
  `settings.conf` as `script_face=liberation`.

## Verification

- `every_face_round_trips_through_its_key` covers the new settings key.
- `settings_script_font_switches_the_page_face` selects Liberation Mono in the
  real Settings UI and checks that the editor and PDF both receive it.
- `every_script_face_exports_a_pdf` exports with every face, including
  Liberation Mono.
- `liberation_mono_exports_latin_and_cyrillic` exports the A95 fixture, checks
  that the page count matches the editor, extracts both Latin and Cyrillic
  text, and confirms the font is embedded.
- `16_settings_appearance` and `30_settings_theme_menu` were regenerated for
  the updated face description; version-only snapshots were refreshed.
- Full workspace tests, clippy `-D warnings`, `cargo fmt --check`,
  `cargo deny check` and `git diff --check` pass before the release commit.
