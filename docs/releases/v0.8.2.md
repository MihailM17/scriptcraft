# ScriptCraft v0.8.2

Released: 2026-11-12

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8.2 ships the redesigned Draft Comparison workspace, the first user-visible
improvement after the v0.8.1 maintenance refactor.

- **Compare header:** split into a title row (with a `Read-only` badge),
  a selection row (base/target selectors, `Unified` / `Side by side` switch,
  `Previous change` / `Next change`, `Open in editor`) and a summary row
  (coloured added/removed/changed counts plus a keyboard-hint line).
- **Diff rows:** each changed row now carries a colour tint and a rounded
  `+`/`-`/`~` marker badge, with an accent bar on the selected row.
- **Inline edits:** changed lines highlight the edited span — old text struck
  through in red, new text in green — instead of hiding the old text behind a
  hover tooltip. Long prefixes are windowed so the edit itself stays visible.
- **Side by side:** old/new cells are tinted and separated by a divider.
- **Change list:** scenes are grouped as cards with a scene-number badge and
  coloured `+n` / `−n` / `~n` counts; filters keep their labelled counts
  (`All 2`, `Added 0`, `Changed 2`, …).

The redesign is visual only: comparison stays read-only, keyboard behaviour
(`J`/`K`, arrows, `V`, `Enter`, `Esc`) and all filter labels are unchanged.

## Verification

- Full workspace gate green: `cargo fmt --all -- --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`, `cargo deny check`, `git diff --check`.
- Compare interaction tests pass (open, filter, navigate, jump, close,
  read-only).
- New `inline_diff` unit tests cover prefix/suffix trimming, insertions,
  deletions and Cyrillic text; snapshots regenerated (`14_compare_drafts`,
  `15_compare_side_by_side`) plus new `21_compare_light`.
- CI run on the release commit is green.

## Compatibility and data safety

- No data format, save or import/export behaviour changed.
- Compare continues to read only; no project or revision history mutation.

## Known limitations / deferred

- **macOS distribution:** ad-hoc signed unless built with Developer ID +
  notarisation (ignored while there is no Apple Developer account). Users may
  need to allow the app in system settings.
- **Windows:** unsigned packages; SmartScreen instructions apply (see
  `docs/release-checklist.md`).
- **Auto-update:** deferred — no silent updater.
- **Still out of scope for v0.8:** collaboration, plugins, production
  breakdowns, DOCX/RTF, spellcheck, AI.
