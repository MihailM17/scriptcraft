# ScriptCraft v0.8.1

Released: 2026-11-12

> macOS DMG in this release is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. Auto-update is deferred.

## Highlights

v0.8.1 is a maintenance release that finishes the v0.8 M9 refactor. It ships
the same features as v0.8.0 with **no intended behavior change**; the goal is
a smaller, easier-to-continue codebase.

- **Settings module:** `AppSettings`, the persisted `settings.conf` load/save
  path, the three preference pages and the reset action now live in
  `scriptcraft-app/src/settings.rs`.
- **Export module:** the Export Scenario window, tabs and format selection now
  live in `scriptcraft-app/src/export.rs`; preview/export still run through the
  existing PDF/FDX/Fountain paths.
- **Research module:** the research tree and every pane (script metadata and
  page locks, title page, logline/synopsis, versions/revisions, entry editor
  and photos) now live in `scriptcraft-app/src/research.rs`. Pane side effects
  return explicit actions that the app applies after the frame.
- **Smaller monolith:** `app.rs` dropped from 8,483 to 7,225 lines. No
  big-bang rewrite; each module was extracted separately.

## Verification

- Full workspace gate passes: `cargo fmt --all -- --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`, `cargo deny check`, `git diff --check`.
- All 19 UI snapshots are byte-identical to v0.8.0; 52 interaction tests pass.
- Bench smoke run before tagging; results stay within the budgets in
  `docs/benchmarks.md`.

## Compatibility and data safety

- `.kitsp` read/write, sidecar identity, atomic saves, recovery copies and the
  crash restore flow are unchanged.
- Fountain and Final Draft `.fdx` import/export are unchanged.
- No project or settings file format changed; v0.8.1 opens existing files
  directly.

## Known limitations / deferred

- **macOS distribution:** ad-hoc signed unless built with Developer ID +
  notarisation (ignored while there is no Apple Developer account). Users may
  need to allow the app in system settings.
- **Windows:** unsigned packages; SmartScreen instructions apply (see
  `docs/release-checklist.md`).
- **Auto-update:** deferred — no silent updater.
- **CI:** macOS runs full tests/snapshots; Linux/Windows run runtime smoke and
  interaction tests but not pixel snapshot baselines.
- **Still out of scope for v0.8:** collaboration, plugins, production
  breakdowns, DOCX/RTF, spellcheck, AI.
