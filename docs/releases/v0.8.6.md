# ScriptCraft v0.8.6

Released: 2026-11-16

> macOS DMG is **ad-hoc signed** (no Developer ID/notarisation).
> Windows/Linux artifacts are unsigned. Do not claim signed/notarised
> distribution. True auto-update is deferred: the app can check for a newer
> release and open its page, but cannot install it.

## Highlights

v0.8.6 is the writing surface the way a writer expects it: every space you
type stays where you typed it, Latin and Cyrillic share one type design, the
paper can print plain black on white while the rest of the app keeps its
theme, Tab offers the story's characters instead of making you retype names,
and Research lists what the script already contains.

### Typing

- **Every space keeps its own cell.** A run of spaces used to render as a
  single cell, so a second or third space was invisible and the caret could
  not sit between them. Pages now show the source text exactly as typed:
  consecutive spaces, leading spaces and trailing spaces all survive, in the
  editor and in the exported PDF. Only the run that causes a line wrap is
  swallowed by the break, as before. Single-space paragraphs paginate
  byte-identically to previous releases.

### Page typography

- **IBM Plex Mono is the default page face.** Courier Prime has no Cyrillic
  glyphs, so each Cyrillic character was being drawn by a different font with
  a different x-height and baseline — the reason Latin looked smaller and
  higher on the same line. IBM Plex Mono draws both scripts in one design at
  the same metrics. Courier Prime remains available as the "classic, Latin
  only" face.
- **Choose the page face.** Settings ▸ Scenario Editor ▸ Page offers IBM Plex
  Mono, Courier Prime and **Courier New** with a live Latin/Cyrillic sample.
  The editor and the exported PDF follow the choice. All three share the page
  grid (12 pt / 0.6 em), so no page break moves between faces.
- **Courier New comes from the system, not the app.** Its licence does not
  allow redistribution, so ScriptCraft reads the installed Windows/macOS file
  at start-up instead of bundling it; when the computer does not have it, pages
  are drawn with Courier Prime and Settings says so. The PDF embeds the same
  bytes the editor uses.
- **Monochrome paper.** Theme ▸ Monochrome paper prints a white page with
  black ink while panels, menus and toolbars keep the selected palette. Caret,
  selection, current-line band and page numbers switch to ink and grey;
  revision marks stay coloured.

### Themes

- **A palette for every desk.** Settings ▸ Theme holds 28 palettes in one
  dropdown, grouped under **ScriptCraft** and **Omarchy** headings. The popup
  has a solid, always-visible scrollbar and a fixed height, so the long list
  reads as a list rather than hiding below the fold.
- **KIT Scenarist.** A light palette that imitates KIT's warm-grey chrome and
  orange mark: `#F3F1EE` panels, near-white paper, `#C96A12` accent. It is the
  closest match yet for writers arriving from KIT.
- **Every base Omarchy palette.** Catppuccin, Catppuccin Latte, Ethereal,
  Everforest, Flexoki Light, Gruvbox, Hackerman, Jade Horse, Kanagawa, Last
  Horizon, Lumon, Lupine, Matte Black, Matcha, Nord, Retro 82, Ristretto, Rosé
  Pine, Solitude, Starship, Tokyo Night, Vantablack and White — 23 in total,
  imported from basecamp/omarchy's `themes/*/colors.toml` backgrounds,
  foregrounds and accents. Panel, page, border and muted-text roles are derived
  from those colors with one rule set, and every palette is checked against the
  same contrast floors: 7:1 body text, 3:1 secondary text and accents, 4.5:1
  accent text, 3:1 misspelling underline, and a revision edge that stays
  locatable on the page.
- **Monochrome paper moved.** The checkbox now sits directly under the theme
  picker on Settings ▸ Application instead of inside Scenario Editor, because
  it modifies the theme.

### Updates

- **Check for updates.** Settings ▸ Application shows the running version, a
  Check for updates button and the last result: up to date, a newer version, or
  a short "couldn't check" note whose hover text explains why. The check runs
  on a background thread and asks GitHub for the latest release, so the editor
  never blocks.
- **A prompt when a release exists.** The app checks once when it opens. If a
  newer version is published, a modal names both versions and offers **Download
  update** (opens that release's page) or **Later**. It cannot install anything
  by itself: this build is ad-hoc signed and has no updater, so the writer
  replaces the app the same way they installed it. Offline or rate-limited
  launches fail quietly to "couldn't check".

### Writing flow

- **Tab picks a character.** Press Tab in an empty character cue and the
  story's characters open in a dropdown: arrows move the highlight, Enter or
  Tab commits, Escape closes and leaves the cue empty. Parenthetical
  extensions are folded, so `ИВАН` and `ИВАН (V.O.)` are one choice. Research
  characters that the script has not used yet are offered after the script's
  own cues, so a planned character is reachable before they first speak.
  Shift+Tab still cycles back through element types, and a cue that already has
  text keeps the previous Tab behaviour.
- **Research recognises the script.** Research ▸ Characters and ▸ Locations now
  list what the draft contains, live: a cue or scene heading typed in the
  editor appears the next time you open the tab, with a count, an "Add N
  missing …" button and a per-name "Add NAME" button. Cards are never deleted;
  entities that exist only in Research are listed under "Only in Research".
  Clicking a folder row now selects its pane.

### Title page

- **The draft date and REVISED block are on the page.** Both were laid out on
  the KIT slot grid, whose A4 pitch put the draft date at −2.3 mm and the
  REVISED block at −16.6 mm — below the paper edge, so neither ever appeared
  in the preview or the PDF. The draft date is now anchored 22 mm above the
  page bottom and REVISED heading/name/date at 40/35/30 mm, keeping their KIT
  slot indexes and field order. Tests assert every non-empty title-page line
  lands inside the paper, with and without an active revision.

## Upgrade notes

- The page face defaults to IBM Plex Mono. Projects do not store a face, so
  opening an older file shows the new default until you pick Courier Prime or
  Courier New in Settings. Courier New needs the operating system's own copy;
  without it the page silently uses Courier Prime at identical metrics.
- Existing saves need no migration: the new preferences are the app-wide
  `script_face=` and `paper_mono=` settings, and the title-page anchors change
  only where the date and REVISED block are drawn.
- Omarchy's Rosé Pine is the light Dawn palette, so a project stored on
  `rose-pine` now opens light; Tokyo Night, Nord and Gruvbox use Omarchy's
  exact values instead of the earlier approximations. Theme keys are unchanged,
  so settings keep their choice.
- Page count for single-space documents is unchanged; documents with runs of
  multiple spaces may now show those spaces and therefore differ from older
  exports, which is the intended fix.

## Deferred

Developer ID signing and notarisation, Windows code signing and **true
auto-update** remain deferred (external credentials). ScriptCraft can tell you a
release exists and open its page; it cannot install it.
