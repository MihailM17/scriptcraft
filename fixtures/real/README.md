# Real-world fixtures

This directory is for compatibility files we have the right to redistribute.
It is intentionally empty until a fixture has a provenance note.

## Policy

- No copyrighted screenplay or production draft without written permission.
- No personal contact details, addresses or unpublished production data.
- Prefer one-scene or few-scene files that isolate a format feature.
- Keep the original file untouched; document any synthetic edits.

## Provenance template

Copy this block into the fixture's own `README.md` or into this file:

```text
File:
Created with: <application> <version> on <OS>
Source: <author/company or "synthetic">
Permission: <written permission reference, or "created by the ScriptCraft team">
Date added:
Purpose: <omitted scene / dual dialogue / revisions / title page / other>
Known differences from a production file:
```

## What we need first

1. A Final Draft `.fdx` with an omitted scene.
2. A Final Draft `.fdx` with dual dialogue.
3. A KIT `.kitsp` with the same two features, if KIT supports them.
4. A `.fdx` with at least two revision colours.
5. A title page with Revised fields and non-ASCII text.

Before adding a file, read `docs/format-spikes.md` and record the findings
there. The fixture is evidence; the spike note is the conclusion.
